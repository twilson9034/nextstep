# NextStep foundation
Neurodivergent-first, optional modules, low cognitive load, no punitive streaks. Default Midnight #080D17, cyan #06B6D4, compact spacing, 8px corners. Development only. Phase 1 initial shell: local preferences, brain dump, authentication, navigation. Remaining: secure per-account cloud preferences, household roles/invitations, offline sync, accessibility and automated tests. Later: tasks, calendar, kitchen and evidence-based dietary profiles, cleaning, family, finance, routines. Never store private health data in public GitHub or service worker caches. Pages source must be GitHub Actions; configure Supabase redirect URLs before signup testing.
